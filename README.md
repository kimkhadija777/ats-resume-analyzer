# 📄 ats-resume-analyzer

An AI-powered Resume Analyzer built with Python, Streamlit, Groq API,
PDF/DOCX text extraction, and structured JSON.

The application compares a user's resume with a specific job description
and provides an AI-based analysis.

---

## 🚀 Features

- Upload PDF resume
- Upload DOCX resume
- Paste job description
- AI-powered resume analysis
- Overall match score
- Matching skills
- Missing skills
- ATS keyword analysis
- Resume problems
- Personalized recommendations
- Experience match
- Education match
- Final result
- Structured JSON output
- Groq model selection
